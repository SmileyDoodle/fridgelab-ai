# FridgeLab AI 🍳

A cozy recipe generator that suggests meals based on ingredients you have in your fridge.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS
- Cloudflare Pages Functions

## Getting Started

### Development

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
npm run preview
```
